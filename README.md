# Finbot

A financial question-answering chatbot built with LangChain and Gradio. It answers questions from [Zerodha Varsity](https://zerodha.com/varsity/) chapters using retrieval-augmented generation (RAG), and includes a small agent that fetches the latest stock news from Yahoo Finance.

## How it works

1. **Load the content.** Finbot reads the Varsity chapter sitemap and loads every chapter page with `WebBaseLoader`.
2. **Index it.** Pages are split into 1,000-character chunks, embedded with OpenAI embeddings, and stored in an in-memory Chroma vector store.
3. **Answer questions.** A history-aware retriever rewrites follow-up questions into standalone ones. `gpt-4o-mini` then answers from the retrieved chunks, in three sentences or fewer.
4. **Chat in the browser.** A Gradio interface gives you the chat window, plus "Delete Previous" and "Clear" buttons.
5. **Fetch news.** A LangChain agent with `YahooFinanceNewsTool` answers a sample question about Indian stock market news and prints the result to the terminal.

## Requirements

- Python 3.14 (the version it was tested with)
- An OpenAI API key

## Setup

```powershell
git clone https://github.com/kankbokans/Finbot.git
cd Finbot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

On macOS/Linux, activate with `source .venv/bin/activate`.

Create a `.env` file in the project root:

```
OPENAI_API_KEY=your-key-here
USER_AGENT=finbot
```

`.env` is listed in `.gitignore`, so your key won't be committed.

## Usage

```powershell
python finbot.py
```

The script loads and embeds every Varsity chapter, then prints a local URL and a public share link for the chat UI. After that, it runs the Yahoo Finance news agent and prints its answer. Press **Ctrl+C** to stop.

Example questions:
- "What is an index fund?"
- "Where to buy stocks?"

## Notes

- **Startup is slow and costs money.** Every run re-downloads and re-embeds all chapters, which uses OpenAI embedding credits. Nothing is saved to disk between runs.
- **The share link is public.** `share=True` creates a `gradio.live` link that anyone can open, and every question they ask is billed to your API key. To keep the app local only, remove `share=True` from `demo.launch()`.
- **Not financial advice.** Answers are generated by an LLM from educational content and may be wrong.
