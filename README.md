# Finbot

A financial question-answering chatbot built with LangChain and Gradio. It answers questions from [Zerodha Varsity](https://zerodha.com/varsity/) chapters using retrieval-augmented generation (RAG), and includes a small agent that fetches the latest stock news from Yahoo Finance.

## How it works

1. **Load the content.** Finbot reads the Varsity chapter sitemap and loads every chapter page with `WebBaseLoader`.
2. **Index it.** Pages are split into 1,000-character chunks, embedded with OpenAI embeddings, and saved to a local Chroma vector database in `chroma_db/`. Later runs load it from disk instead of re-embedding.
3. **Answer questions.** A history-aware retriever rewrites follow-up questions into standalone ones. `gpt-4o-mini` then answers from the retrieved chunks, in three sentences or fewer.
4. **Chat in the browser.** A Gradio interface gives you the chat window, plus "Delete Previous" and "Clear" buttons.
5. **Fetch news.** A LangChain agent with `YahooFinanceNewsTool` answers a sample question about Indian stock market news and prints the result to the terminal.

## Requirements

- Python 3.14 (the version it was tested with)
- An OpenAI API key

## Setup

```powershell
git clone https://github.com/kankbokans/Finbot.git
cd Finbot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

On macOS/Linux, activate with `source .venv/bin/activate`.

Create a `.env` file in the project root:

```
OPENAI_API_KEY=your-key-here
USER_AGENT=finbot
```

`.env` is listed in `.gitignore`, so your key won't be committed.

## Usage

```powershell
python finbot.py
```

On the first run, the script downloads and embeds every Varsity chapter and saves the result to `chroma_db/`, which takes about two minutes. Later runs load the saved database in a few seconds. The script then runs the Yahoo Finance news agent and prints its answer. Finally, it starts the chat UI and prints a local URL and a public share link. Press **Ctrl+C** to stop.

Example questions:
- "What is an index fund?"
- "Where to buy stocks?"

## Evaluation

`evaluation.py` tests Finbot against 35 questions in `eval_queries.json`. Each question lists the Varsity chapters that answer it and a reference answer written from those chapters.

- **Retrieval:** checks whether the right chapters are found, using MAP@3 and Recall@3. Precision@3 and F1@3 are printed for reference.
- **Generation:** `gpt-4o-mini` acts as a judge. It scores each answer for groundedness (is it supported by the retrieved text?) and completeness (does it cover the reference answer?).
- **Report:** a summary table, likely failure patterns, and a pass / review / block release gate.

```powershell
python evaluation.py
```

The evaluation uses the same `chroma_db/` as the chatbot, so it scores exactly the index Finbot serves. A full run makes about 105 `gpt-4o-mini` calls.

Results:

| Layer | Metric | Score | Target |
|---|---|---|---|
| Retrieval | MAP@3 | 0.86 | ≥ 0.80 |
| Retrieval | Recall@3 | 0.90 | ≥ 0.70 |
| Retrieval | Correct chapter ranked first | 31 of 35 questions | — |
| Generation | Groundedness | 0.98 | ≥ 0.85 |
| Generation | Completeness | 0.88 | ≥ 0.75 |

Every metric meets its target, so the release gate passes.

## Notes

- **Rebuilding the index.** The saved database isn't updated automatically. Delete `chroma_db/` to pick up new Varsity content, or if a first run was interrupted partway. The next run rebuilds it, which uses OpenAI embedding credits.
- **The share link is public.** `share=True` creates a `gradio.live` link that anyone can open, and every question they ask is billed to your API key. To keep the app local only, remove `share=True` from `demo.launch()`.
- **Not financial advice.** Answers are generated by an LLM from educational content and may be wrong.
