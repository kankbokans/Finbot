Finbot

A financial question-answering chatbot that answers from Zerodha Varsity's educational content using retrieval-augmented generation.

View on GitHub

Features

Grounded answers

Answers come from retrieved Varsity chapters, not the model's memory. If the answer isn't in the content, Finbot says it doesn't know.

Follow-up questions

A history-aware retriever rewrites follow-ups into standalone questions, so the conversation keeps its context.

Chat interface

A Gradio web UI with example prompts, plus buttons to undo the last turn or clear the chat.

Market news agent

A LangChain agent uses the Yahoo Finance news tool to fetch the latest headlines about stocks such as Infosys.

How it works

  1. Load: reads the Varsity chapter sitemap and downloads every chapter page.
  2. Index: splits pages into 1,000-character chunks, embeds them with OpenAI embeddings, and saves them in a local Chroma database, so later runs start in seconds.
  3. Retrieve: finds the chunks most relevant to your question, taking chat history into account.
  4. Answer: gpt-4o-mini writes a concise answer from the retrieved chunks, in three sentences or fewer.

Evaluation

Finbot is tested against 35 questions. Each question lists the Varsity chapters that answer it and has a reference answer written from those chapters. Every metric meets its target.

0.86

MAP@3: relevant chapters are found and ranked near the top

0.90

Recall@3: share of relevant chapters found in the top three

31 / 35

Questions where the correct chapter is the first result

0.98

Groundedness: answers are supported by the retrieved text

0.88

Completeness: answers cover the reference answer

Groundedness and completeness are scored by an LLM judge (gpt-4o-mini).

Run it yourself

git clone https://github.com/kankbokans/Finbot.git
cd Finbot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
echo OPENAI_API_KEY=your-key-here > .env
python finbot.py
python evaluation.py

You'll need your own OpenAI API key. See the README for full setup details.
